# TimeTetris - 스마트 스케줄 매니저

## 📋 개요
TimeTetris는 일정을 시간에 맞춰 테트리스처럼 효율적으로 배치하는 웹 기반 스케줄링 프로그램입니다. 사용 가능한 시간대(세션)에 여러 일정을 자동으로 최적 배치하여 시간 활용을 극대화합니다.

## 🚀 시작하기

### 설치 없이 바로 실행
1. `index.html` 파일을 웹 브라우저에서 열기
2. 첫 실행 시 예시 데이터 로드 여부 선택
3. 바로 사용 시작!

### 지원 브라우저
- Chrome (최신 버전)
- Safari (최신 버전) 
- Edge (최신 버전)

## 💡 주요 기능

### 1. 세션 관리
- **세션**: 사용 가능한 시간대를 의미
- 날짜, 시작 시간, 지속 시간 설정
- 활성화/비활성화 기능
- 예: "월요일 15:00-16:00", "화요일 09:00-09:30"

### 2. 일정 관리
- **일정**: 배치해야 할 작업이나 사람
- 이름, 메모, 우선순위 설정
- 여러 가능한 시간대 지정 가능
- 예: "김민준 학생 - 영어 수업"

### 3. 자동 배치
- 우선순위 기반 스마트 배치 알고리즘
- 최대 매칭 알고리즘으로 효율적 배치
- 배치 결과 즉시 확인

### 4. 시각화
- 캘린더 뷰 (월/주/일 보기)
- 배치 상태 색상 구분
  - 🟢 초록색: 배치 완료
  - 🟡 노란색: 미배치
  - 🔵 파란색: 빈 세션

### 5. 데이터 관리
- 자동 저장 (브라우저 localStorage)
- JSON 파일로 내보내기/불러오기
- 전체 초기화 기능

## 📖 사용 시나리오

### 시나리오 1: 영어 과외 선생님
```
상황: 3명의 학생, 월/수/금 오후 3-8시 수업 가능
1. 세션 추가: 월/수/금 각 시간대별로 세션 생성
2. 일정 추가: 각 학생의 가능한 시간대 입력
3. 자동 배치 실행
4. 결과 확인 및 조정
```

### 시나리오 2: PT 트레이너
```
상황: 5명의 회원, 화/목 9-22시 PT 가능
1. 세션 추가: 30분 단위로 세션 생성
2. 일정 추가: 각 회원의 선호 시간대 입력
3. 우선순위 설정 (신규 회원 우선 등)
4. 자동 배치 및 최적화
```

## 🎮 사용법

### 기본 워크플로우
1. **세션 추가**: "세션 관리" → "새 세션 추가"
2. **일정 추가**: "일정 관리" → "새 일정 추가"  
3. **자동 배치**: "자동 배치" → "배치 실행"
4. **결과 확인**: "캘린더 뷰"에서 시각적 확인
5. **수동 조정**: 필요시 개별 배치 수정
6. **내보내기**: 결과를 JSON 파일로 저장

### 팁
- 우선순위가 높은 일정이 먼저 배치됩니다
- 여러 시간대를 지정하면 배치 가능성이 높아집니다
- 세션을 비활성화하면 해당 시간은 배치에서 제외됩니다

## 🔧 기술 스택
- Pure HTML/CSS/JavaScript
- FullCalendar 라이브러리 (캘린더 뷰)
- Font Awesome (아이콘)
- LocalStorage API (데이터 저장)
