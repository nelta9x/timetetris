# 세션 스케줄러 프로그램 사양서

## 1. 프로젝트 개요

### 1.1 목적
사용자들의 가능한 시간대를 기반으로 정해진 세션 시간에 최대한 많은 사용자를 자동으로 배치하는 웹 기반 스케줄링 프로그램

### 1.2 핵심 기능
- 사용자 및 가능 시간대 관리
- 세션 정의 및 설정
- 자동 배치 알고리즘
- 상태 저장/불러오기 (JSON)
- 인터랙티브 UI/UX

### 1.3 기술 요구사항
- 순수 웹 클라이언트 애플리케이션 (서버 불필요)
- 최신 브라우저만 지원 (Chrome, Firefox, Safari, Edge 최신 버전)
- 로컬 스토리지 활용 가능

## 2. 데이터 모델

### 2.1 사용자 (User)
```json
{
  "id": "string",
  "name": "string",
  "email": "string (optional)",
  "mobile": "string (optional)",
  "availableSlots": [
    {
      "type": "slot_number | datetime",
      "value": "number | ISO 8601 datetime string",
      "duration": "number (minutes, optional)"
    }
  ],
  "maxSessions": "number | null (null = 무제한)", // 기본 1
  "assignedSessions": ["sessionId"],
  "priority": "number (optional, for future use)", // 기본 1 클 수록 우선순위 높음
  "metadata": "object (optional)"
}
```

### 2.2 세션 (Session)
```json
{
  "id": "string",
  "name": "string",
  "type": "individual | group",
  "timeSlot": {
    "type": "slot_number | datetime",
    "value": "number | ISO 8601 datetime string",
    "duration": "number (minutes)"
  },
  "maxParticipants": "number (1 for individual)",
  "assignedUsers": ["userId"],
  "requirements": {
    "minParticipants": "number (optional)",
    "tags": ["string"] (optional)
  },
  "metadata": "object (optional)"
}
```

### 2.3 설정 (Configuration)
```json
{
  "allowMultipleSessions": "boolean",
  "randomSeed": "number (optional)",
  "timeSlotDefinitions": [
    {
      "id": "number",
      "label": "string",
      "datetime": "ISO 8601 (optional)"
    }
  ],
  "constraints": {
    "maxIterations": "number",
    "prioritizeFullSessions": "boolean"
  }
}
```

## 3. 기능 명세

### 3.1 사용자 관리

#### 3.1.1 사용자 추가/편집/삭제
- 개별 사용자 정보 입력
- 벌크 임포트 (CSV/JSON)
- 사용자 목록 표시 (테이블/카드 뷰)
- 검색 및 필터링

#### 3.1.2 가능 시간대 설정
- 드래그 앤 드롭으로 시간 슬롯 선택
- 캘린더 뷰에서 날짜/시간 선택
- 복수 시간대 일괄 선택
- 시간대 템플릿 저장/적용

### 3.2 세션 관리

#### 3.2.1 세션 생성/편집/삭제
- 세션 정보 입력 폼
- 세션 유형 선택 (1:1 / 그룹)
- 최대 참가자 수 설정
- 시간 슬롯 할당

#### 3.2.2 세션 시각화
- 타임라인 뷰
- 캘린더 뷰
- 목록 뷰
- 세션별 참가자 현황

### 3.3 자동 배치 알고리즘

#### 3.3.1 배치 전략
```
1. 모든 사용자와 세션의 가능한 매칭 조합 계산
2. 제약 조건 검증
   - 사용자의 가능 시간대
   - 세션 최대 인원
   - 사용자별 최대 참여 세션 수
   - 시간 충돌 (중복 참여 불가 설정 시)
3. 무작위 배치 실행
   - Fisher-Yates 셔플 알고리즘 사용
   - 최대 매칭 문제 해결 (Maximum Matching)
4. 결과 최적화
   - 배치되지 않은 사용자 최소화
   - 세션 충족률 최대화
```

#### 3.3.2 배치 옵션
- 시드값 설정 (재현 가능한 무작위)
- 부분 배치 허용/금지
- 수동 조정 가능

### 3.4 결과 관리

#### 3.4.1 배치 결과 시각화
- 전체 배치 현황 대시보드
- 사용자별 배정 세션 표시
- 세션별 참가자 목록
- 미배치 사용자 하이라이트

#### 3.4.2 수동 조정
- 드래그 앤 드롭으로 사용자 이동
- 배치 잠금/해제
- 변경 이력 추적
- 실행 취소/재실행

### 3.5 데이터 입출력

#### 3.5.1 저장 기능
- 전체 상태 JSON 내보내기
- 로컬 스토리지 자동 저장
- 다운로드 파일 생성
- 버전 관리 (선택적)

#### 3.5.2 불러오기 기능
- JSON 파일 업로드
- 드래그 앤 드롭 지원
- 데이터 유효성 검사
- 병합/덮어쓰기 옵션

#### 3.5.3 내보내기 형식
- CSV (사용자 목록, 배치 결과)
- PDF 리포트
- 캘린더 파일 (ICS)
- 이메일 템플릿

## 7. 개발 고려사항

### 7.1 기술 스택 권장
- **프레임워크**: React
- **상태 관리**: Redux/Zustand 또는 Vuex/Pinia
- **UI 라이브러리**: Ant Design
- **드래그 앤 드롭**: react-dnd, vue-draggable
- **차트/시각화**: D3.js, Chart.js
- **캘린더**: FullCalendar, react-big-calendar
- **파일 처리**: PapaParse (CSV), jsPDF (PDF), webp

### 7.2 프로젝트 구조
```

    /user
    /session
    /scheduler
    /common
  /utils
    /algorithms
```

1. 프로그램 실행 및 초기 설정

4. 자동 배치 실행

- **상담 센터**: 상담 시간 예약
- **팀 미팅**: 1:1 면담 스케줄링

### 시나리오 예시
#### 1: 영어 과외 선생님
"나는 영어 과외 선생님이고, 10명의 학생이 있다.
- 월/수/금 오후 3-8시 사이에 수업 가능
- 각 수업은 1시간
- 학생별로 가능한 시간이 다름
- 겹치지 않게 자동으로 배치하고 싶음"
- 학생A: 월 3-5시, 수 4-6시 가능
- 학생B: 월 4-6시, 금 3-5시 가능
