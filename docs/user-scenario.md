## user-scenario.md

### 시나리오 1: 영어 과외 선생님
"나는 영어 과외 선생님이고, 10명의 학생이 있다.
- 월/수/금 오후 3-8시 사이에 수업 가능
- 각 수업은 1시간
- 학생별로 가능한 시간이 다름
- 겹치지 않게 자동으로 배치하고 싶음"

### 예시 데이터:
학생A: 월 3-5시, 수 4-6시 가능
학생B: 월 4-6시, 금 3-5시 가능
...

### 시나리오 2: PT 선생님
"나는 PT 선생님이고, 11명의 회원이 있다.
- 나는 화/목 오전 9시 - 오후 10시까지 수업 가능
- 회원은 주 1회 ~ 주 3회까지 참여하고 싶은 횟수가 다름
- 각 수업은 30분
- 회원별로 가능한 시간이 다름
- 1명씩 겹치지 않게 최대한 배치하고 싶음
- 시간대에 배치가 안 될 경우 빠르게 확인하고 싶음.
"

### 예시 데이터:
회원A: 화 3-5시, 수 4-6시, 일 9-18 가능. 최대 주 2회 희망.
회원B: 월~목 언제든 가능. 최대 주 1회 희망.
회원C: 월, 화, 금 언제든 가능. 최대 주 3회 희망.
...
